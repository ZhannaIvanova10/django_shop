# Интернет-магазин на Django

Учебный проект интернет-магазина для курса Django.

## Технологии
- Python 3.13.3
- Django 4.2+
- Bootstrap 5
- SQLite

## Установка
1. Клонировать репозиторий
2. `py -m venv venv`
3. `source venv/Scripts/activate` (для Git Bash) или `venv\Scripts\activate` (для CMD)
4. `pip install -r requirements.txt`
5. `py manage.py migrate`
6. `py manage.py runserver`
