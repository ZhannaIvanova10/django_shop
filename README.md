# Интернет-магазин на Django

Учебный проект интернет-магазина, разрабатываемый в рамках курса по Django.

## 📋 Описание проекта
Этот проект представляет собой каркас интернет-магазина, который будет постепенно дорабатываться в течение курса. В текущей версии реализованы базовые страницы и функциональность.

## 🛠 Технологии
- **Python 3.13.3** - основной язык программирования
- **Django 6.0.1** - веб-фреймворк
- **Bootstrap 5** - CSS-фреймворк для стилизации
- **SQLite** - база данных для разработки
- **PostgreSQL** - настроена через переменные окружения для продакшена
- **Pillow** - работа с изображениями
- **psycopg2-binary** - драйвер PostgreSQL
- **python-dotenv** - управление переменными окружения

## 📁 Структура проекта

│ ├── templates/ # Шаблоны приложения
